# Page Laravel très simple

Cette base contient les fichiers Laravel nécessaires pour une page simple :

- Route : `routes/web.php`
- Vue Blade : `resources/views/simple.blade.php`

## Si vous partez d'un projet Laravel complet

1. Copier ces fichiers dans votre projet Laravel.
2. Lancer le serveur :

```bash
php artisan serve
```

3. Ouvrir `http://127.0.0.1:8000`.
